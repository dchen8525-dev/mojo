输入区改版 · 5 个皮肤

结构已经定下来了（就是紧凑那一版），这 5 个文件的 DOM 完全一样，只换皮肤。

共用 base.css + demo.js，每个文件只有十来行 <style> 覆盖变量。两个下拉是真能点的，工具卡能展开。

这一版的结构
  • 无顶栏、无底部状态栏，只留左侧会话侧栏。
  • 输入卡片：上文本域；卡片内底行 = 左「＋」/ 右「模型 ⌄ · 发送」（空输入时发送置灰）。
  • 卡片外下方一条左对齐工具行：左端 📁 选择工作空间 ⌄ 和 ⓘ 权限模式 ⌄；右端 ses_id · ctx · 成本 · 后台任务。
  • PLAN 已并进权限下拉，成为第四档「PLAN 计划模式（只读探索，先出计划待批准）」，不再单独占一个开关。
  • 点「选择工作空间」→ 上浮菜单：最近项目 + 「打开文件夹…」；选完按钮文字变成该目录名（默认是占位文案）。
两处说明
  • 演示切换器（欢迎页 / 对话 / 授权弹窗）已整个去掉，页面固定展示对话状态。
  • 「授权弹窗」（写文件时那个确认弹窗）也从 demo 里去掉了 —— 它原来只能从那排切换器进入。真实 GUI 里它照旧存在，不受这次改动影响；要重新看它的样子我可以单独出一个。
