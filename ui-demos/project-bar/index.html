「打开项目」下移 · 5 个方案

把项目入口从顶部面包屑搬到底部输入区，和模式切换、模型下拉、发送按钮做成一家人。

5 个方案共用同一套外壳与 Porcelain 主题（base.css + demo.js），差异只在项目入口的位置与形态，方便横向比较。每个页面右下角可切「欢迎页 / 对话 / 授权弹窗」，工具卡可点击展开，项目控件可点开浮层。

共同点
  • 顶栏不再显示项目路径；顶栏只剩会话标题 + 会话 id。
  • 点击项目控件 → 既有行为不变：Electron 弹原生目录选择框，浏览器版弹路径输入。
  • 方案 1/2/4 额外给了「最近项目」列表（需要新增一个最近目录的持久化，约 20 行）；3/5 没有。
V1底栏面包屑bottom crumb

项目就是底栏最左端一段轻量文本「📁 D:\work\mojo ▾」，和原来顶栏的面包屑长得一样，只是搬到了模型/模式那一行。点击在输入区上方展开浮层。

改动移动 1 个按钮 + 换位置

占用低（长路径会省略号）

改动最小观感不变路径易被截断

V2药丸 + 最近项目面板chip + popover

项目是一枚带边框的 chip「📁 mojo ▾」，显示目录名而不是全路径，视觉权重和旁边的模式分段控件一致。点击展开 320px 面板：搜索框 + 最近项目 + 浏览。

改动新按钮样式 + 浮层 + 最近列表

占用低（只显示目录名）

切换最快视觉对齐多一个列表要维护
打开预览 →
V3输入框上方上下文条context strip

项目放在输入框正上方一条细 mono 行：📁 路径 │ ⎇ 分支 │ 会话名。底栏因此保持纯净（只有模式 / PLAN / 模型 / 发送）。顺手把整个顶栏也去掉了。

改动新增一条 strip，删掉顶栏

占用多一行高（但顶栏省回来了）

分层最清楚底栏最干净纵向多一层

V4统一分段控件segmented group

把底栏左侧原有的三组东西（项目 / 模式 / PLAN）收进一个带边框的分段控件：[📁 mojo ▾] │ [默认 自动 YOLO] │ [PLAN]，项目是它的第一格。
