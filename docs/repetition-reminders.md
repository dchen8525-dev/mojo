# 重复调用异常提醒

## 状态

- 2026-10-22 落地（本批）。

## 机制

`RepetitionTracker`（`src/repetition.ts`）在**单个用户回合内**跟踪连续的
「工具名 + 规范化输入」完全一致调用：

- 输入按 key 排序序列化，键顺序不同视为同一调用。
- 连续相同调用达到 3 次、以及此后每满 3 次（3/6/9…）时返回警告计数；
  任何输入或工具名变化都会重置计数。
- `Agent.chat` 在每轮工具结果写入后注入一条
  `<system-reminder event="RepetitionDetected" tool="...">` 用户消息，指出重复次数，
  并要求查看最新结果、改变输入/策略，或向用户说明阻塞点。

跟踪器是回合局部变量，不跨用户消息累积。子代理内部循环不在本机制覆盖范围内。

## 设计取舍

相同调用重复三次以上而结果不可能变化，通常意味着模型陷入循环；提醒比继续消耗轮次更便宜。
每 3 次重复再次提醒，避免首次提醒被忽略后无限重复。
